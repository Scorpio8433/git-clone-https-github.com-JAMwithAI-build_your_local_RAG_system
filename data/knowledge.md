# Local RAG Assistant Knowledge

This project is a starter local RAG system built to help users ask questions about files stored on their own machine.

A RAG system works by:
1. Reading local documents
2. Splitting them into chunks
3. Converting chunks into embeddings
4. Searching the most relevant chunks
5. Sending those chunks to a language model for a grounded answer

This repo is designed to be a simple, understandable example for JAMwithAI and local AI experimentation.

If you want to ask questions, open the app and enter a prompt such as:
- What is this project about?
- How does RAG work?
- What files are included in the knowledge base?

This sample file helps the app start with a working default knowledge base.
